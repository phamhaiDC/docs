Điểm chính
❌
"Astra phải qua WINE mới cài được MSSQL" là không đúng
Từ bản 2017, SQL Server có bản Linux native, không cần Wine. Nhiều khả năng đây là nhầm lẫn với tài liệu chính thức của r_keeper (docs.rkeeper.ru), vốn hướng dẫn chạy chính r_keeper 7 (file .exe) qua Wine với PostgreSQL làm CSDL.
⚠️
Debian và Astra Linux không nằm trong danh sách hỗ trợ của Microsoft
Microsoft chỉ hỗ trợ RHEL, SLES (đến 2022) và Ubuntu LTS. Khi có sự cố trên Debian/Astra, Microsoft có thể yêu cầu tái hiện lỗi trên cấu hình được hỗ trợ (KB4047326).
🔒
SQL Server 2012 chỉ chạy trên Windows và đã hết mọi hỗ trợ
Hết extended support 12/07/2022, hết ESU 08/07/2025. Chạy qua WINE không dùng được cho production. Hướng đúng: backup → restore lên SQL 2022, giữ compatibility level 110 trong lúc kiểm thử.
✅
Nếu bắt buộc dùng Astra: chạy VM KVM (guest Ubuntu) hoặc container chính thức
Hai cách này tránh xung đột thư viện (OpenSSL, libldap) và giữ SQL Server trên môi trường Microsoft hỗ trợ. Cài gói Ubuntu trực tiếp lên Astra chỉ nên dùng cho lab.

Fact Có nguồn kiểm chứng (ưu tiên Microsoft Learn, wiki Astra, docs.rkeeper.ru).   Inference Suy luận từ các fact, cần thử nghiệm hoặc xác nhận.   Chưa xác minh Nguồn thứ cấp hoặc chưa đối chiếu được.

Danh sách distro/CU của Microsoft thay đổi theo từng bản CU (trang release notes cập nhật lần cuối 10/2026). Cần kiểm tra lại ngay trước khi triển khai.

Thông tin nền Astra Linux
  • Fact Astra SE 1.8 phát hành 01/08/2024, dựa trên Debian 12 (Bookworm), kernel 6.1 LTS (được ИСП РАН rà soát) và 6.6.
  • Fact Astra SE 1.7 dựa trên Debian 10 (Buster).
  • Chưa xác minh Kernel 5.4/5.15/6.1 cho 1.7; kernel 6.12 và bản 1.8.4 (~10/2025) — lấy từ blog, cần đối chiếu release notes chính thức.
  • Fact Repo main của Astra 1.8 có docker.io 25.0.5. Astra khuyến nghị chế độ rootless, nhưng rootless không hỗ trợ khi dùng kernel hardened.
  • Fact Không có bài wiki chính thức nào của Astra về cài MSSQL; SQL Server không có trong chương trình "Ready for Astra". Với MySQL, wiki Astra ghi rõ là không cài được — Astra chỉ bảo đảm DBMS đã chứng nhận.
  • Fact Trung tâm Eureca (St. Petersburg) đã cài SQL Server 2017 bản Linux native trên Astra CE 1.11/2.11 bằng gói Ubuntu + dpkg --ignore-depends=openssl, không dùng Wine.
Chế độ bảo mật cần thử nghiệm

ЗПС (môi trường phần mềm khép kín): khi bật sẽ chặn file ELF và thư viện không có chữ ký số. Ở mức "Усиленный" ЗПС có sẵn nhưng mặc định tắt. Từ 1.8 có bsign-integrator để ký file.

Inference Nếu khách hàng bật ЗПС, binary trong /opt/mssql sẽ bị chặn cho đến khi được ký bằng khóa tổ chức. Mandatory integrity control (МКЦ) cũng có thể ảnh hưởng dịch vụ chạy nền.

Ba cách triển khai SQL Server trên Astra
Khuyến nghị cho production

A. VM KVM, guest Ubuntu 22.04/24.04

Ưu: SQL Server nằm trên cấu hình Microsoft hỗ trợ; không xung đột thư viện; ít bị ЗПС/МКЦ ảnh hưởng.

Nhược: quản trị 2 lớp OS; mất vài % hiệu năng.

Phù hợp lab / dev / prod có kiểm soát

B. Container chính thức Microsoft

mcr.microsoft.com/mssql/server:2022-latest trên Docker 25 của Astra 1.8, mount volume XFS/ext4 vào /var/opt/mssql.

Ưu: thư viện đóng gói sẵn, gần native. Nhược: host Astra là vùng xám; cần thử rootless + kernel hardened.

Không khuyến nghị cho production

C. Cài gói Ubuntu trực tiếp

Ưu: hiệu năng tốt nhất.

Nhược: phải tự xử lý OpenSSL/libldap; dễ hỏng khi cập nhật OS; phải ký binary nếu bật ЗПС; không có hỗ trợ chính thức.

Rủi ro bản quyền (chỉ khi triển khai cho thực thể tại Nga)

Fact Microsoft tạm dừng bán mới tại Nga từ 04/03/2022; theo nguồn thứ cấp, khách hàng Nga không gia hạn được subscription sau 30/09/2023. Thị trường Nga chuyển sang PostgreSQL (Postgres Pro, Tantor) có sẵn trong hệ sinh thái Astra.

Inference Với Dcorp tại Việt Nam, việc mua license không bị ảnh hưởng trực tiếp.

Đường chuyển dữ liệu từ SQL 2012
  • Fact SQL 2022 hỗ trợ compatibility level 100–160, nên CSDL 2012 (level 110) restore lên vẫn giữ level 110.
  • Fact Backup từ SQL 2008 trở lên restore được lên SQL 2025 nếu level ≥ 100.
  • Fact Từ Windows sang Linux không có in-place upgrade, luôn đi đường backup → restore. Backup không restore ngược về bản cũ hơn được.
  • Fact CSDL SQL 2014 có In-Memory OLTP không restore được sang SQL Server on Linux.

Yêu cầu phía r_keeper / UCS
  • Fact Tài liệu r_keeper yêu cầu "MS SQL Server 2012 hoặc mới hơn" (một số trang ghi 2014+). Trang r_k Delivery ghi SQL 2012 chỉ được hỗ trợ đến 01/07/2025 → chính UCS đã ngừng xem 2012 là nền tảng hỗ trợ.
  • Fact r_keeper 7 hỗ trợ PostgreSQL từ 7.06.05.412; từ 7.06.05.459 dùng được ở các điểm không có StoreHouse 5 và Interactive Reports.
  • Inference Máy chủ StoreHouse 5 (sdbserv) là ứng dụng Windows, vẫn cần Windows hoặc Wine, bất kể SQL Server chạy ở đâu.

Câu hỏi mở / chưa xác minh
  • Mức đánh giá riêng của SQL Server 2012 trên WineHQ AppDB (AppDB chặn truy cập tự động).
  • Ngày cụ thể SQL 2025 hết mainstream (Microsoft Learn chỉ ghi năm 2031).
  • Kernel mặc định Ubuntu; kernel 6.12 và bản 1.8.4 của Astra.
  • Khuyến nghị "XFS thay ext4 trên kernel < 5.6" (nguồn thứ cấp Aryasoft, chưa thấy trong tài liệu Microsoft).
  • Astra 1.8 dựa trên gói Debian 12 nhưng đã thay đổi đáng kể — hướng dẫn chạy được trên Debian 12 chưa chắc chạy nguyên trạng trên Astra.
